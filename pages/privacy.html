Privacy

What this page actually needs to say

ProjectPulse, as it exists right now, is a static prototype — there is no server, no database, and no account system behind it. We'd rather tell you plainly what that means than paste in boilerplate that wouldn't be true here.

Where your data lives

Everything you see — teams, milestones, submissions, notifications — is stored only in your own browser's localStorage. Nothing is sent to a server, because there is no server to send it to. Clearing your browser's site data for this page, or opening it in a different browser or device, will reset it back to the seed demo data.

No real accounts, no real collection

Signing in simply selects a demo user profile already built into the app — no password, email, or personal information is collected or transmitted anywhere. Any names, teams, or projects you see are demo data, not records of real people.

If this becomes a real service later

Should ProjectPulse ever move beyond a prototype into a deployed service with real accounts, this page would need to be replaced with an actual privacy policy describing real data handling. Until then, this note reflects the honest state of the demo.

See also the Terms page for the same kind of plain statement about what this project is.
